<h1 align="center">SAM (Steam 成就管理器) - Decky Loader 插件</h1>

<p align="center">
  <em>专为 [Decky Loader Russia (deckyloader.ru)](https://www.deckyloader.ru/) 目录制作</em>
</p>

---

**SAM** 是适用于 **Steam Deck** (SteamOS) 上 [Decky Loader](https://decky.xyz/) 的原生插件，可让您直接在游戏模式（快捷访问菜单 QAM）中灵活管理 Steam 成就。

### 🎯 为什么需要此插件？
- **多周目重玩：** 可以重新锁定已获得的成就，在重新通关喜爱的游戏时再次体验解锁成就的快感。
- **修复故障成就：** 如果由于游戏 Bug 或网络连接故障导致成就未能正常解锁，您可以轻松手动补全。
- **Steam Deck 原生体验：** 无需切换到桌面模式，也无需通过 Proton 运行外部 Windows 工具 — 完全原生、响应迅速并针对掌机手柄操作进行了深度优化。

## ✨ 功能特性
- 🎮 **自动识别运行中的游戏：** 通过 Decky Loader API 自动检测。
- ⚡ **一键管理：** 支持单个成就的锁定与解锁，亦支持批量操作（「全部解锁」/「全部锁定」）。
- 📜 **跑马灯与自适应界面：** 超长成就名称平滑滚动，精致方形按钮完美适配 QAM 面板。
- 🔍 **搜索与筛选：** 支持按名称实时搜索，以及「全部 / 已解锁 / 未解锁」筛选。
- 🌍 **完整 30 种语言本地化：** 插件界面及成就名称、描述均与您的 Steam 客户端语言自动同步。
- 🛡️ **内置多层安全保护：**
  - **永久禁用 VAC 游戏：** 搭载 Valve 反作弊（如 CS2、TF2 等）的游戏被永久拦截。
  - **多人游戏保护机制：** 默认禁用多人游戏；仅在未运行游戏时可在设置中由用户自行承担风险开启。
  - **清晰的状态提示：** 针对非 Steam 快捷方式和无成就的游戏提供友好提示卡片。

## ⚠️ 安全与风险提示
在在线多人游戏中修改成就可能违反游戏开发商的政策。
- 插件**永久禁止**访问受 **VAC (Valve Anti-Cheat)** 保护的游戏。
- 默认情况下多人游戏处于拦截状态。开启该功能需由您自行承担风险。
- 强烈建议主要在单人游戏中使用此插件。

## 📦 安装指南
1. 从最新 [Releases](https://github.com/Kowalski-coder/SAM-for-Decky-Loader/releases) 或 [deckyloader.ru](https://www.deckyloader.ru/) 下载 `SAM.zip`。
2. 按 `...` 键打开快捷访问菜单并前往 **Decky Loader** 标签页。
3. 点击齿轮图标（Decky 设置）-> **Developer** -> **Install plugin from ZIP**。
4. 选择下载的 `SAM.zip` 文件并确认安装。
