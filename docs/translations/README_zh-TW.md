<h1 align="center">SAM (Steam 成就管理器) - Decky Loader 外掛程式</h1>

<p align="center">
  <em>專為 [Decky Loader Russia (deckyloader.ru)](https://www.deckyloader.ru/) 目錄打造</em>
</p>

---

**SAM** 是適用於 **Steam Deck** (SteamOS) 上 [Decky Loader](https://decky.xyz/) 的原生外掛程式，讓您能直接在遊戲模式（快捷選單 QAM）中輕鬆管理 Steam 成就。

### 🎯 為什麼需要此外掛程式？
- **重玩遊戲體驗：** 能夠重新鎖定已取得的成就，在重溫喜愛的作品時重拾解鎖成就的樂趣。
- **修復問題成就：** 若因遊戲錯誤或連線問題導致成就未能正常取得，您可以快速手動解鎖。
- **Steam Deck 原生體驗：** 無需切換至桌面模式，亦無須透過 Proton 執行外部 Windows 程式 — 完全原生且完美支援搖桿操作。

## ✨ 功能亮點
- 🎮 **自動偵測執行中遊戲：** 透過 Decky Loader API 自動獲取。
- ⚡ **一鍵快速操作：** 支援單一成就鎖定/解鎖，以及「全部解鎖」/「全部鎖定」批次管理。
- 📜 **跑馬燈文字與緊湊排版：** 長標題自動滑動跑馬燈，精美方形按鈕無縫融入介面。
- 🔍 **搜尋與篩選：** 依標題關鍵字即時搜尋，支援「全部 / 已解鎖 / 未解鎖」切換。
- 🌍 **完整支援 30 種語言：** 外掛介面及成就名稱、說明皆與您的 Steam 語系保持一致。
- 🛡️ **內建嚴格防護體系：**
  - **絕對封鎖 VAC 遊戲：** 支援 Valve Anti-Cheat 的遊戲（如 CS2、TF2）永久禁止使用。
  - **多人遊戲保護：** 預設封鎖多人連線遊戲；僅在未啟動遊戲時可於設定中自行開啟。
  - **詳細狀態卡片：** 針對非 Steam 捷徑與無成就遊戲顯示明確提示。

## ⚠️ 安全與風險注意事項
在多人連線遊戲中修改成就可能違反遊戲廠商規範。
- 外掛程式**永久封鎖**受 **VAC (Valve Anti-Cheat)** 保護的遊戲。
- 多人遊戲支援預設為關閉狀態，啟用風險由使用者自負。
- 建議主要於單人單機遊戲中使用。

## 📦 安裝步驟
1. 從最新 [Releases](https://github.com/Kowalski-coder/SAM-for-Decky-Loader/releases) 或 [deckyloader.ru](https://www.deckyloader.ru/) 下載 `SAM.zip`。
2. 按 `...` 鍵開啟快捷選單並前往 **Decky Loader**。
3. 點選齒輪圖示（Decky 設定）-> **Developer** -> **Install plugin from ZIP**。
4. 選取下載好的 `SAM.zip` 進行安裝。
