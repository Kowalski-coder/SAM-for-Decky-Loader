<h1 align="center">SAM (Steam Achievement Manager) для Decky Loader</h1>

<p align="center">
  <em>Створено спеціально для каталогу [Decky Loader Russia (deckyloader.ru)](https://www.deckyloader.ru/)</em>
</p>

---

**SAM** — нативний плагін для [Decky Loader](https://decky.xyz/) на **Steam Deck** (SteamOS), що дозволяє гнучко керувати досягненнями Steam прямо з ігрового режиму (Quick Access Menu).

### 🎯 Навіщо потрібен цей плагін?
- **Повторне проходження:** Дозволяє заблокувати (скинути) вже отримані досягнення, щоб заново пережити емоції від їх відкриття під час нового проходження улюбленої гри.
- **Виправлення забагованих досягнень:** Якщо через помилку у грі чи збій мережі досягнення не зарахувалося, ви можете розблокувати його вручну.
- **Зручність на Steam Deck:** Не потрібно переходити у режим робочого столу або запускати сторонні exe-програми через Wine/Proton — усе працює нативно та оптимізовано під геймпад.

## ✨ Можливості
- 🎮 **Автоматичне визначення запущеної гри** через API Decky Loader.
- ⚡ **Керування в один дотик:** Розблокування або блокування як окремих досягнень, так і масові дії («Розблокувати все» / «Скинути все»).
- 📜 **Рухомий рядок та адаптивний інтерфейс:** Довгі назви досягнень плавно прокручуються, квадратні кнопки ідеально пасують панелі QAM.
- 🔍 **Пошук та фільтрація:** Пошук за назвою, фільтри: Всі / Отримані / Закриті.
- 🌍 **Повна локалізація на 30 мов:** Інтерфейс плагіна та назви й описи досягнень завантажуються мовою вашого клієнта Steam.
- 🛡️ **Вбудована система безпеки:**
  - **Повна заборона ігор із VAC:** Ігри з Valve Anti-Cheat (CS2, TF2 тощо) блокуються автоматично й безповоротно.
  - **Захист для мультиплеєра:** Мережеві ігри заблоковані за замовчуванням. Увімкнення доступне лише коли гра не запущена.
  - **Інформаційні повідомлення:** Зрозумілі підказки для сторонніх ігор (Non-Steam) та ігор без досягнень.

## ⚠️ Попередження про безпеку та ризики
Зміна досягнень в онлайн-іграх може порушувати правила окремих розробників.
- Плагін **назавжди блокує** доступ до ігор із захистом **VAC (Valve Anti-Cheat)**.
- Робота з мультиплеєром за замовчуванням вимкнена. Ви вмикаєте її на власний ризик.
- Рекомендується використовувати плагін переважно в одиночних іграх.

## 📦 Встановлення
1. Завантажте `SAM.zip` з останнього [Релізу](https://github.com/Kowalski-coder/SAM-for-Decky-Loader/releases) або каталогу [deckyloader.ru](https://www.deckyloader.ru/).
2. У Quick Access Menu (кнопка `...`) відкрийте вкладку **Decky Loader**.
3. Натисніть на значок шестерні (Налаштування Decky) -> **Developer** -> **Install plugin from ZIP**.
4. Виберіть завантажений архів `SAM.zip`.
