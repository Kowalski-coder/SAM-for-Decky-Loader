<h1 align="center">SAM (Steam 実績マネージャー) for Decky Loader</h1>

<p align="center">
  <em>[Decky Loader Russia (deckyloader.ru)](https://www.deckyloader.ru/) 専用に開発</em>
</p>

---

**SAM** は **Steam Deck** (SteamOS) の [Decky Loader](https://decky.xyz/) 向けネイティブプラグインです。ゲームモード（クイックアクセスメニュー QAM）から直接 Steam の実績を快適に管理できます。

### 🎯 なぜこのプラグインが必要なのか？
- **再周回プレイの楽しみ：** 獲得済みの実績をリセット（ロック）し、大好きなゲームを最初からやり直す際に再び実績解除の達成感を味わえます。
- **バグで解除されなかった実績の救済：** ゲームのバグや通信エラーで正当に解除されなかった実績をワンタップで手動解除できます。
- **Steam Deck ネイティブ動作：** デスクトップモードへの切り替えや Proton 経由での Windows 外部ツール起動は不要です。コントローラー操作に完全最適化されています。

## ✨ 主な機能
- 🎮 **起動中のゲームを自動検出：** Decky Loader API と連携。
- ⚡ **ワンタップで簡単操作：** 各実績の個別切り替えに加え、「すべて解除」「すべてリセット」の一括操作に対応。
- 📜 **マーキー表示と見やすいUI：** 長い実績名もスムーズにスクロール表示。コンパクトな四角ボタンで快適操作。
- 🔍 **検索とフィルター：** 実績名でのキーワード検索、すべて / 解除済み / 未解除の切り替え。
- 🌍 **Steam 全30言語に完全対応：** プラグインUIだけでなく、実績名や説明文もお使いの Steam 言語で自動取得。
- 🛡️ **万全のセキュリティ機能：**
  - **VAC 保護タイトルの完全遮断：** Valve Anti-Cheat（CS2、TF2 等）採用ゲームは完全にブロックされます。
  - **マルチプレイヤー誤爆防止：** オンラインゲームはデフォルトで保護。ゲーム非起動時のみ設定から自己責任で許可可能。
  - **親切な状態カード：** 非Steamゲームや実績非対応タイトルを自動判別して案内を表示。

## ⚠️ 安全上の注意とリスク
オンラインゲームでの実績改変は利用規約に抵触する恐れがあります。
- 本プラグインは **VAC (Valve Anti-Cheat)** 対象ゲームへのアクセスを**恒久的に拒否**します。
- マルチプレイヤー対応は標準で無効化されています。利用時は自己責任となります。
- シングルプレイヤーゲームでのご利用を強く推奨します。

## 📦 インストール方法
1. 最新の [Releases](https://github.com/Kowalski-coder/SAM-for-Decky-Loader/releases) または [deckyloader.ru](https://www.deckyloader.ru/) から `SAM.zip` をダウンロードします。
2. `...` ボタンを押してクイックアクセスメニューの **Decky Loader** タブを開きます。
3. 歯車アイコン（Decky 設定）-> **Developer** -> **Install plugin from ZIP** を選択します。
4. `SAM.zip` を選択してインストールします。
